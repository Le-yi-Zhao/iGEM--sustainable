# GALATEA Sustainable Development Impact - working website

Static GitHub Pages-ready site for the Tsinghua-T iGEM 2026 GALATEA Sustainable Development Impact workstream.

## Deploy with GitHub Pages

1. Commit this folder to the root of `Le-yi-Zhao/iGEM--sustainable`.
2. Ensure `index.html` and `.nojekyll` are in the repository root.
3. In GitHub: Settings -> Pages -> Build and deployment -> Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Wait for the Pages deployment to finish.

The site has no external JavaScript or CSS dependencies.
