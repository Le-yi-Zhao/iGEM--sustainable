## 当前可写的结论

光甘草定的微生物生产已有外部文献可行性证据。本项目尚无匹配组产率、纯度、资源清单或成品安全实测。模型比较不能证明其整体更安全：部分终点分数较低，但 ADMET-AI 皮肤反应分数高于五种固定参照，其他平台存在遗传毒性等分歧。优先补充分析方法、生产效应及局部安全验证。

资源强度比 = 批次资源消耗比 / 纯产物质量比。资源比 1.1、纯产物比 1.2 时，对应强度降低 8.3%；资源比 1.5、产物比 1.2 时，强度提高 25%。两者均为假设。纯产物质量为分离样品质量乘质量分数；不能重复乘回收率。缺失清单不填零。

## 下一步需要的结果

### 优先一：产物身份与定量

需要：标准品对照、色谱保留时间和质谱确认；标准曲线、空白、加标回收、检出限与定量限；胞内外样品分别定量。

建议结果图：标准品与样品色谱叠图、校准曲线和回收率表。

能够支持：确认测到的是光甘草定，并建立可信的浓度和质量基础。

限制：没有身份或定量验证时，峰面积增长不能写成产量增长。

### 优先一：匹配组生产性能

需要：低表达 OC/DMT 无相分离基线 G1，与相同背景的相分离组；匹配宿主、培养与底物条件。以独立培养批次为重复，预先确定主要终点和统计方法，先导方差用于估计样本量。

建议结果图：原始重复点、滴度和生产强度、组间效应量与置信区间；报告所有预设组。

能够支持：若增益稳定且不确定性可接受，支持在所测试条件下提高生产性能。

限制：若无改善或区间跨越无差异，应报告未观察到明确增益；技术重复不能替代生物学重复。

### 优先一：六种化合物的时间序列

需要：统一记录化合物 9、10、11、13、14、15、前体消耗、培养体积、取样体积、时间及 OD600；同时关注胞内外分布和总回收。

建议结果图：中间体与产物随时间变化、摩尔转化率、质量平衡。

能够支持：判断产物提升是否伴随底物利用改善、中间体积累减少或泄漏变化。

限制：浓度变化仅提供机制线索；未测支路和取样损失会限制质量平衡。

### 优先二：相分离机制与负担

需要：凝聚体成像、动态交换或可逆性证据、酶分配与表达量；加入表达匹配且失去相分离能力的对照，同时测生长负担。

建议结果图：代表图与定量、动态恢复曲线、表达量和生长曲线。

能够支持：把生产效应与空间组织机制关联，并评估额外表达负担。

限制：出现亮点不能单独证明液液相分离，也不能排除表达量改变造成的效应。

### 优先一：纯化、杂质与资源清单

需要：分离产物质量、光甘草定质量分数、回收率和残留溶剂；逐批记录培养与纯化的水、溶剂、原料、废物、电耗及价格来源。

建议结果图：按 1 g 纯光甘草定归一化的材料、水、溶剂、电耗和成本图；附清单完整性。

能够支持：只有匹配边界内强度下降，才能支持对应资源效率改善；不将所有指标合成任意总分。

限制：产率增加不自动等于节能、低碳或更低成本；缺少记录不能填零。额定功率只支持估算。

### 优先二：护肤安全与配方可行性

需要：明确用量、配方、停留时间与暴露场景；优先验证致敏、眼刺激、遗传毒性分歧和稳定性；由具备资质的团队选择适用方法及对照。

建议结果图：方法适用性、剂量响应、原始重复与结论边界；配方稳定性及杂质变化。

能够支持：建立在具体配方与暴露条件下可解释的安全证据，决定是否继续开发及怎样控制风险。

限制：模型分数和参照物排名不能确定人体安全浓度；模型间分歧不能用投票消除。

### 优先二：环境释放与生物安全

需要：记录收集、处理前后菌落计数或验证过的替代指标、方法检出限；评估处理后残留物和排放路径。

建议结果图：处理前后活菌或残留物结果、检出限和去向记录。

能够支持：支持所验证处理条件下的控制效果；结合暴露数据安排生态风险验证。

限制：低于检出限不等于绝对为零；水生毒性预测不等于已测排放浓度或实际环境风险。

### 优先二：访谈与设计反馈

需要：补齐提到的三份访谈原文、日期、角色和引用许可；按关切—证据—设计修改—反馈验证编码，两人复核分歧。

建议结果图：匿名证据矩阵及设计修改前后对照；必要时展示覆盖人数而非总体比例。

能够支持：说明使用者、产业和专家意见如何改变具体设计。

限制：当前未收到三份原文，不能生成引语或声称已完成访谈挖掘；小样本不代表公众总体。

## 数据与复现

源数据库未被改写。原始校验和与虚拟机归档位置见 `data/literature/input_manifest.json`。默认复现使用已提交派生数据和预测缓存，不重新训练或请求外部模型。

```sh
LD_LIBRARY_PATH=/root/miniconda3/lib /root/autodl-tmp/IGEM/.venv/bin/python analysis/run_all.py
```

重新审计原始数据库：

```sh
/root/autodl-tmp/IGEM/.venv/bin/python -m analysis.models.literature_audit /root/IGEM-storage/source_archives/literature_database_source.csv.gz
```

字段说明：`source_record` 是去掉表头后的逻辑记录序号，不是文件物理行号；`approved_for_titer=false` 表示未核准用于目标生产数值汇总；`SCENARIO` 表示条件计算。色谱时间序列模板新增化合物 13，其余六化合物参照范围与既有项目清单一致。三份访谈原文尚未提供，未生成原话或统计。

## 资源模板补充字段

`purity_fraction` 使用 0–1 的质量分数，纯度缺失不计算资源强度。`material_inventory_complete` 和 `equipment_inventory_complete` 只有在清单边界核实完整后填写 `true`；空白不能视作完整。

`material_type` 填 `water`（水）、`solvent`（溶剂）或 `other`（其他）。体积转质量所需 `density_g_per_ml` 单位为 g/mL，并填写 `density_source`。缺少密度时不输出总投入质量强度。`power_source` 区分实测与额定等估算来源；`batch_samples` 为有依据的共享分摊数量。

资源核算已修正纯度校正、液体质量遗漏和缺失清单被填零的问题。当前所有实测模板仍为空，因此未产生项目资源强度。
