# GALATEA sustainability analysis package

This directory documents the current analysis logic for the Sustainable Development Impact working page.

Current analyses that can be completed before final wet-lab results:

1. Stakeholder -> Metric mapping.
2. SDG 3 / 12 / 9 evidence mapping.
3. Protocol -> Process inventory.
4. Core production system boundary.
5. Wet-lab data gap audit.

Quantitative analyses that should be run only after measured data are available:

- Titer, Yield, Productivity.
- Substrate consumption and biomass-normalized substrate uptake.
- Metabolite 14 / 9 / 10 / 11 / glabridin time series.
- Material-flow or Sankey plots based on defensible quantitative balances.
- PMI, water intensity, solvent intensity, waste intensity and process energy intensity.
- Basic cost per gram, sensitivity and uncertainty.

Important: do not convert relative chromatographic peak areas into a mass-flow Sankey unless the analytical method supports that interpretation. Keep Measured / Fitted / Predicted / Literature-Database / Scenario evidence visibly separated.
