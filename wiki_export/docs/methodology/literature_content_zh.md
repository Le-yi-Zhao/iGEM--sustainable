# 文献内容分析：从研究布局到光甘草定项目依据

本轮纳入完整的 20,567 条记录、1,397 个不同 DOI，不按质量字段进一步过滤。原始数据归档及哈希见 `data/literature/input_manifest.json`。

## 分析问题

1. 宿主、研究对象和反应体系之间如何分布？
2. 酵母与黄酮类通路是否有可借鉴的知识基础？
3. 表达、前体、空间组织及过程优化如何在文献中共同出现？
4. 相分离文献用于基础机制、材料、工程工具还是生物合成？
5. 能否从相邻方法与同研究定量案例，提出光甘草定的可检验改进假设？

## 统计定义

每个 DOI 计为一篇文献条目。桑基图使用源表 `best_host_group`、`best_product_family`、`best_reaction_system_type_value`：先将同义类别合并，再取同篇非缺失类别的记录众数；并列归为多类别并列。不存在可映射类别时保留未标注。全体文献始终纳入，各列合计均为 1,397。

主题识别仅使用标题及已抽取的相关证据句；完整正则与字段列表随结果输出。标题命中和标题加证据句命中分别统计，后者可能含背景或引文，不等于作者实际采用该技术。主题可重叠；共现不是协同效果。

黄酮相关集合定义为主对象属黄酮／异黄酮／异戊烯基黄酮，或标题命中指定黄酮词表；酵母集合为任一源记录的宿主组标为酵母；空间组织集合为标题或抽取证据命中相关词表。交集图采用互斥集合计数。所有比例的总体为本项目语料，不外推全球研究量。

相分离应用分类仅在标题命中相分离、凝聚体或复凝聚的 16 篇中进行。按题名依次分为生物合成应用、工程平台与方法、递送与仿生材料、细胞机制与疾病。它是主题分类，不是研究效果评分。

没有可靠年份字段，不从 DOI 的年份片段推断发表趋势。不同产物、单位、宿主及培养条件的滴度不合并平均。

## 支持光甘草定项目的论证

必要性应表述为：既有光甘草定生产研究暴露了多步反应协调与中间体分布等待解决问题；文献库提供酵母、黄酮通路与空间组织的相邻方法，值得设计匹配实验检验能否迁移。路线具有文献依据，并不预先保证相分离能提高产率。

数据库中的甘氨酸例证为 1 小时 5.0 mmol/L 对 3.4 mmol/L，二者相除约 1.47；不能使用该研究相对于另一条路径的 35 倍结果作为相分离单因素增益。依克多因的最终生产水平同样结合了酶工程等变化。二氢槲皮素研究使用有膜过氧化物酶体，不与无膜液液相分离等同。

## 复现与文件

```sh
python -m analysis.models.literature_landscape /root/IGEM-storage/source_archives/literature_database_source.csv.gz
python analysis/run_all.py
```

默认页面重建读取已提交的逐篇分类，不需要重新读取大数据库。首次命令生成 `results/tables/literature_content/` 和 `results/summaries/literature_content.json`。八图位于 `figures/literature_content/`，网页查阅器支持宿主、工程主题及题名／DOI 联合筛选。

主要案例来源：[甘氨酸](https://doi.org/10.1016/j.jcou.2025.103269)、[依克多因](https://doi.org/10.1016/j.enzmictec.2026.110928)、[二氢槲皮素](https://doi.org/10.1186/s12934-025-02773-2)、[酵母共定位综述](https://doi.org/10.3389/fbioe.2021.606795)。光甘草定生产补充文献继续单列，不加入原库计数。
