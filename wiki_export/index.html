01 Challenge and baseline

The primary comparison is matched No-LLPS versus LLPS

The analysis uses G1, low-expression OC/DMT without LLPS, as the baseline and the same OC/DMT background with LLPS as the main comparison. Host, medium, initial OD600, precursor concentration, temperature, RPM and fermentation conditions must be matched. Normal-expression constructs are references; optimization constructs do not replace the primary comparison.

Current status: the comparison is defined, but no matched measurements are present. All process-light variables were removed because the current design no longer uses light control.

ADMET-AI v2 local ensemble

Research question
Which pathway compounds and endpoints should be prioritized for experimental follow-up?
Why this model?
It is an official, locally reproducible multi-task ADMET package with packaged checkpoints and a DrugBank-approved reference distribution.
Input
Canonical SMILES for compounds 9, 10, 11, 13, 14 and 15 after RDKit structure QC.
Dataset / database
41 TDC ADMET tasks; 2,845 packaged DrugBank-approved reference compounds for prediction-space percentiles.
Model version
ADMET-AI 2.0.1; Chemprop 2.3.1; five classification and five regression checkpoints.
Method
Five-member task ensembles; mean prediction and member standard deviation retained for every compound–task pair.
Main result
246 compound–task predictions and 1,230 member-level predictions were generated and cached.
Uncertainty
Between-member standard deviation; an empirical 75th-percentile flag is used only for prioritization.
Applicability domain
Position relative to the packaged DrugBank prediction distribution is shown; it is not a chemical-domain certificate.
Interpretation
Endpoint-specific predicted concern supports model-guided testing.
Limitations
Training-set scope, endpoint imbalance and correlated ensemble members limit confidence; no laboratory toxicity outcome is inferred.

06 Resource energy and cost

Templates follow the working functional unit

The working functional unit is 1 g purified glabridin. Templates capture actual materials, water, solvents, equipment time, power provenance, recovery, purity and price. No PMI, energy intensity or cost result is reported before product mass and batch inventories exist.

Accounting rule: OD-normalized substrate uptake remains a proxy until a strain-specific OD600-to-dry-cell-weight calibration is available. Nameplate power and measured power are reported separately.

python -m venv .venv

.venv/bin/python analysis/run_all.py

The command validates structures, reuses or generates the local ADMET-AI cache, normalizes cached outputs, calculates definition-matched consensus, regenerates figures, rebuilds this site and checks local links. It makes no external API call by default.
